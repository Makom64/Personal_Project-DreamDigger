> 양식: [[Docs/Templetes/IssueTemplate|IssueTemplate]]

개인 프로젝트 단위이나, 작업을 시작하기 전 GitHub Issue를 통해
업무에 대한 내용을 공유하는 연습을 가지고자 한다.

Issue를 통해 읽는 사람은 다음과 같은 내용을 확인할 수 있어야 한다.

1. 담당자가 어떤 작업을 할 것인지(목표)
2. 작업을 하게 된 이유와 현재 상황 (배경)
3. 작업을 단계로 나누어 어떻게 작업할 것인지 (계획)
4. 작업을 하며 주의할 점이나 신경써야 할 부분 (핵심)
5. 해당 작업이 완료되는 기준이 정확히 무엇인지 (완료 기준)
6. 완료 기준을 만족했는지 어떻게 확인할 것인지 (검토 방법)
