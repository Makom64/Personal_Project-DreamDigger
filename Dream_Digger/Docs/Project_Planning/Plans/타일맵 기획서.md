## 1. 블록의 기능

### 파괴

- `파괴 가능`과 `파괴 불가능`으로 나뉨 (파괴는 플레이어가 진행)
- 파괴 불가능하나 아이템을 통해서만 소멸 가능한 블록이 존재

### 자원 생성

- 파괴될 때 자원 블록이면 자원을 파괴된 자리에 생성함

### 점수 상승

- 파괴될 때 블록에 따라 점수가 상승함

### 자원 노출

- 자원을 담은 블록은 블록 위에 자원을 노출시켜 플레이어가 알 수 있게 한다
- 어떤 자원은 담겨도 노출은 되지 않는다. (특수 아이템의 경우)

### 특수 기믹

- 플레이어가 밟고 있는 동안 지속 데미지를 주는 블록
- 이동하다가 멈추면 미끄러지는 블록

---
## 2. 가지는 데이터

- 파괴 가능 여부
- 소멸 가능 여부
- 블록 내구도
- 생성할 자원
- 점수

만약 특수 블록이라면
- 공격력
- 플레이어 이동 거리 증가 (미끄러지도록)
