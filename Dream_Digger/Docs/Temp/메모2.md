## 1. 할당량 방식 (Quota)

1. 전체 높이를 구간으로 나눈다. 비율도 설정할 수 있게 한다. (30%, 40% 50% 등)
2. 구간마다 등급별 개수를 설정한다. 얕으면 Happy 많이, 깊으면 Angry 많이
3. 맵을 순회하면서 구간별 후보 셀 목록을 모은다. 타일이 있는 칸만
4. 후보 목록을 섞은 뒤 앞에서부터 개수만큼 꺼내 배치한다.
5. Specail은 구간 설정과 따로 딱 1번만 배치한다.
- 추천 키워드 : Fisher-Yates Shuffle

## 2. 조건별로 생각해볼 질문

1. enum 순서에 의미를 두면 나중에 새 타입을 중간에 끼우면 어떻게 될까요? 등급이 조용히 바뀔텐데 ㅋ
2. Specail 1개 어떻게 둘건지? 맨 아래 구간에서 랜덤? 아니면 정확한 좌표 지정? 다른 자원이 이미 놓인 칸이랑 겹치지 않게 하려면 배치 순서를 어떻게 할 건지?
3. 설정 가능하게
   - 구간 비율 + 구간별 등급 개수 데이터를 어디에 둘건지?
   - 설정한 개수가 구간의 후보 칸 수보다 많으면 어떻게 처리할 건지? 예외 상황을 정해두어라.

## 3. 광맥 관련 키워드

1. Random Walk / Drunkard's Walk : 시작점에서 랜덤하게 한 칸씩 이동하며 칠해요. 가장 직관적이고, "광맥 1개 = N칸"이라 할당량 방식과 잘 맞는다.
2. Flood Fill / BFS 확장 : 시작점에서 주변 칸으로 확률적으로 퍼져 나간다. 둥근 덩어리 모양이 나온다.
3. Perlin Noise : 맵 전체에 부드러운 값 지도를 깔고 임계값보다 높은 곳에 배치한다. 자연스럽지만 개수를 맞추기 어렵다.
4. Cellular Automata : 동굴 생성에 주로 쓰인다. 광맥보다는 지형 쪽이다.

검색해볼만한 키워드 :
- procedural ore generation
- Terraria world generation ore

## 4. 추천 순서

우선 광맥 없이 할당량 배치를 완성하고, 그 다음 "칸 1개 배치"에서 "시작점 1개 + RandomWalk로 N칸"으로 바꿔보기. 구조를 처음부터 확장할 수 있게 짜두면 나중에 편하다.
