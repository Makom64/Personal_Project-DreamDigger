| 작업 목록                    | 세부 · 특이사항                          |

## 2. 진행한 작업

오늘 하루 어떤 작업을 진행했는지, 작업 중이나 작업이 완료된 후 알게 된 특이사항을 적는다.

| 작업 목록                    | 작업 내용 중 특이사항                                                             |
| :----------------------- | ------------------------------------------------------------------------ |
| 1. 플레이어와 타일맵 마찰력 문제 해결   | - 플레이어에게 물리 2D 머테리얼 적용<br>- 타일맵의 rigidbody - BodyType을  Static으로 변경      |
| 2. 타일 내 데이터 선언 후 상호작용 시험 | - 플레이어 방향키 위/아래 추가<br>- 플레이어 상호작용 키 추가 후 스크립팅<br>- 플레이어 상하좌우 좌표 구하는 식 추가 |

## 3. 작업 중 막힌 부분

작업 중 막혔다면 '어떤 작업 중'이었는지, '어디서' 막혔는지, 추측한 '원인'은 무엇인지,
문제를 해결했다면 발견한 원인, 해결한 방식과 같은 과정을 적는다.

- 플레이어가 그리드 내 셀 좌표를 받고, 해당 좌표에 타일 유무와 타일 내 데이터 접근하는 기능을 구현하다 막혔다.
