## 3. 작업 중 막힌 부분

작업 중 막혔다면 '어떤 작업 중'이었는지, '어디서' 막혔는지, 추측한 '원인'은 무엇인지,
문제를 해결했다면 발견한 원인, 해결한 방식과 같은 과정을 적는다.

- 자동 맵 생성 기능
	- 타일 별 설치 층 수를 읽고 설치를 진행하는 반복문 메서드와 맵 크기를 읽고 내구도를 부여하는 식의 순서에서 오류가 발생했으나 메서드 순서를 MapController에서 조절하도록 한 곳에 모았다.
- 광물 자동 배치 기능
	- 구역 별 세로 길이를 알 수 있기 때문에 MapGenerator의 인스펙터에서 구역 마다 어떤 광물을 등장 시키게 할지 열거형을 고를 수 있게 하였으나, 가중치와 광맥같은 개념을 어떻게 처리할지 몰라 자료 조사 시작.
